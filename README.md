# Roman Umyarov

I build AI-powered tools that solve real problems and ship them to production.

## Projects

**TvoyMeet** — cross-platform desktop app (Win/Mac) for meeting transcription. faster-whisper + FFmpeg + customtkinter. Outputs structured .md ready for LLM input. Packaged as a native installer.

**NPS Feedback Analyst** — three-mode feedback analysis pipeline: local NLP (offline), Gemini 2.5 Flash, Ollama. Includes prompt injection protection, MD5 caching, and post-LLM number verification. Telegram bot as the interface.

**Winx Bot** — aiogram 3 + GigaChat. Reads team chat messages, extracts tasks, maps them to assignees, returns structured JSON to a dedicated topic. Runs on VPS as a systemd service.

**FIFA26 Predictor** — ML model for match result prediction.
