# Роман Умяров

Строю AI-инструменты под реальные задачи. Довожу до продакшена.

## Проекты

**ТвойMeet** — десктопное приложение (Win/Mac) для транскрибации встреч. faster-whisper + FFmpeg + customtkinter. Выдаёт структурированный .md готовый к подаче в LLM. Собран в нативный инсталлятор.

**NPS Feedback Analyst** — три режима анализа обратной связи: локальный NLP без интернета, Gemini 2.5 Flash, Ollama. Защита от prompt injection, MD5-кэш, верификация цифр после LLM. Telegram-бот как интерфейс.

**Winx Bot** — aiogram 3 + GigaChat. Читает сообщения рабочего чата, извлекает задачи, маппит на исполнителей, возвращает структурированный JSON в тему «Задачи». Работает на VPS как systemd-сервис.

**FIFA26 Predictor** — ML-модель предсказания результатов матчей.

## Стек

`Python` `GigaChat` `GigaCode` `aiogram` `faster-whisper` `pandas` `REST API` `systemd` `PyInstaller`

## О себе

Работаю в молодёжной политике — автоматизирую операционку, масштабирую через обучение команды. Умею объяснять технические решения нетехническим людям и внедрять их в реальные процессы.
